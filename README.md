# ClaimWise AI

A multimodal AI-powered insurance claims assistant built with AWS and Kiro.

## Project Vision

ClaimWise AI helps insurance organizations process motor insurance claims by analyzing:

- Accident video
- Accident photographs
- Audio description of the incident
- Insurance policy documents
- Claimant-provided information

The system uses AI to extract and correlate evidence and provide a preliminary claim assessment to a human claims assessor.

> AI assists the claims assessor. It does not make the final claim approval or rejection decision.
